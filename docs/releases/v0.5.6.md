# 滚猫md v0.5.6

v0.5.6 修复含 HTML 列表的 Markdown 表格无法正常打开的问题。本次发布 Windows 便携版 EXE 与 SHA-256 校验文件；Android 继续使用 [v0.5.5 APK](https://github.com/sonicacd/tumblingcatmd/releases/tag/v0.5.5)。

## 更新内容

- **表格列表兼容**：当表格单元格包含 `<ul><li>…</li><br><li>…</li></ul>` 等写法时，正确识别列表项之间的换行，避免转换时关闭错误的文档节点，导致正文丢失或打开报错。支持有序、无序列表及连续 `<br>`。
- **可重复应用的修复**：修复保存在 Toast UI 的项目补丁中，安装依赖时由 `patch-package` 应用；沿用现有 DOMPurify 净化和滚动同步补丁。
- **浏览器回归**：新增 `npm run test:html-tables`，覆盖表格和嵌套列表、三种视图、三种主题、桌面和窄屏、未修改时精确保留原始源码的保存，以及编辑后保存。

原 Markdown 文件保持原样。缺失的图片附件仍需补齐到文档引用的位置。

## English

v0.5.6 fixes opening errors and missing content when Markdown tables contain HTML lists with `<br>` between list items. Ordered and unordered lists, including repeated separators, retain their structure during conversion. The fix is stored in the existing Toast UI patch and preserves the application's DOMPurify and scroll synchronization patches.

The new `npm run test:html-tables` suite covers table and nested lists, all three views and themes, desktop and narrow layouts, exact unchanged-source saves, and edited saves. Original Markdown files remain unchanged. Missing image attachments still need to be supplied at their referenced locations.

Validation on 2026-11-11 passed 261 JavaScript tests, 17 Rust tests, and 10 browser check groups including the local reproduction document. Browser checks reported no page errors or unexpected dialogs. Reversing and reapplying the dependency patch also passed.

The Windows production build succeeded, including the frontend build in 3.20 seconds and the Rust release build in 2 minutes 34 seconds. Existing bundle-size and dynamic-import warnings remain. The EXE reports file/product version 0.5.6, is 6,654,976 bytes, and contains all four current CSS/JavaScript asset names. Its SHA-256 is recorded above and in both checksum attachments.

This release ships the Windows v0.5.6 portable EXE and SHA-256 files. Android remains at [v0.5.5](https://github.com/sonicacd/tumblingcatmd/releases/tag/v0.5.5). Browser checks use isolated Edge with in-memory file interfaces; native Windows WebView UI and file permissions remain unverified. No Android APK was built for this release.
