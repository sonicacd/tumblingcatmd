    使用帮助

    从这里了解常用操作。关闭后，随时可以从“更多”→“使用帮助”再次查看。

    1. 设置打开方式（Windows）

    1. 更多 → 添加到右键打开方式：添加后，右键点击 Markdown 或 TextPack 文件，在“打开方式”中选择“滚猫md”。
    2. 更多 → 设为默认 .md 程序：打开 Windows 默认应用设置，找到 .md，选择“滚猫md”并确认。以后双击 Markdown 文件即可打开。

    这两项仅 Windows 版提供，无需管理员权限。请先把 EXE 放到常用目录；移动 EXE 后，从新位置运行并重新添加打开方式。

    2. 网页图文与 TextPack

    在网页选中文字和图片，Ctrl + C 复制，再在编辑区 Ctrl + V 粘贴。会保留主要内容顺序、标题、列表和基础样式，复杂排版会简化；无法下载的图片会保留链接。

    想把正文和图片装进一个文件，使用“更多”→“新建 TextPack”，粘贴后保存即可。空白未保存文档成功贴入网页图片时也会自动采用 TextPack。

    已有 Markdown 可用“更多”→“另存为 TextPack”打包本地图片。直接打开 .textpack 可继续编辑，图片随文件移动；已有网络图片会保留原网址。暂不支持直接打开 .textbundle 文件夹。

    导出图片
    “更多”→“导出全文图片”

    Windows 版可将 .md、.markdown、.mdown、.mkd、.txt 或 .textpack 直接拖到窗口打开。

    “导出全文图片”会预览导出进度，一页保存 PNG，长文多页打包 ZIP；最终写入前可以取消。

    “更多”→“插入本地图片”支持 PNG、JPEG、GIF、WebP（每图最多 32 MiB），也可直接粘贴截图。TextPack 将图片保存在文件内；Windows 和 Android 的普通 Markdown 需先保存，图片存入文档旁的 assets 文件夹。

    Windows 会自动显示文档目录内的相对图片。Android 先用“更多”→“关联图片文件夹”授权文档所在目录，需要所用文件管理器支持目录访问。

    本地图片暂不支持 SVG、绝对路径和 ../ 越级路径。普通 Markdown 另存到其他目录时，请一同复制 assets 等图片附件；TextPack 会保留包内图片。

    三个模式中打开查找和替换都会保持当前界面；阅读模式也允许替换，内容会即时刷新。

    普通文档从所见即所得或阅读视图跳转到行时，会切换到源码视图以精确定位。

    点击视图按钮或按 Ctrl+1/2/3 切换时，会尽量保留当前正在阅读的段落位置；文首、文末和大文档也支持位置恢复。 排版与换行差异可能带来少量偏移，缺少可匹配文字时按阅读进度恢复。“跳转到行”优先定位到指定行。

    “大纲”可跳转到章节并标出当前位置；“阅读设置”可完全关闭或重新启用大纲，也可调整字号、行距、1200 / 1600 / 2100 px 或全宽排版。

    “更多”→“最近打开”保留最近 20 份文档，可继续上次阅读。选中文字后，可用“更多”→“选中内容复制为图片”分享；代码块右上角也可以直接复制代码。

    保存与安全

    • 标题栏的 * 和文件名旁的圆点表示有未保存更改。切换文档或关闭前可以保存、放弃更改或取消。
    • 未保存内容会在本机自动保留最多 5 份恢复草稿，可从“更多”→“恢复草稿”找回；请用“保存”写入文档文件。
    • 仅打开有效的 UTF-8 文本（可带 UTF-8 BOM）；其他编码会被拒绝，防止乱码覆盖原文件。
    • 保存采用安全替换流程，并尽量保留 BOM 和原文档的换行风格。
    • 重要文件仍建议另行备份。
